# LevelUp English

A free, static English-learning site:

- **Adaptive placement test** (20 questions) covering grammar, vocabulary, reading and listening — places learners on the CEFR scale A1–C2 and scores each skill separately.
- **Personalised recommendations** — a week-by-week study plan, weakest-skill focus with tips, and links to the right units.
- **12 study units** (2 per level), each with a grammar lesson, vocabulary flashcards, a reading text, auto-marked exercises (multiple choice, gap-fill, word order, listening) and speaking practice with speech recognition.
- **Level tests** to move up a level, plus a progress dashboard. Progress is stored in the browser (localStorage).

No build step: open `index.html` or serve the folder with any static host.

Content lives in `js/data.js` — add questions to `TEST_BANK` or units to `UNITS` to extend the course.
